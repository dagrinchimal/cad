Makes objects bigger or smaller around a base point.

## How to use
1. Select the objects and press **Enter**.
2. Click the base point (it stays where it is).
3. Type the scale factor: `2` doubles, `0.5` halves.

## Options
- **Copy** (`C`): scale a copy and keep the original.
- **Reference** (`R`): pick or type the length something is now, then the length it should be. Handy for scaling a pasted plan so a known wall measures right.

## Tips
- Scaling changes the real size of objects. To print smaller, use a plot scale or a viewport scale instead ([Layouts and printing](help:layouts)).
