Makes lines and arcs longer until they reach the nearest object.

## How to use
1. Start **Extend**.
2. Click each object **near the end** you want lengthened.
3. Press **Enter** when done.

## Several at once
- Click empty space and click again to draw a **fence**: every object it crosses is extended at the end nearest the fence.
- **Crossing** (`C`) uses a box instead.

## Options
- **Shift-click**: trims that object instead.
- **Undo** (`U`): undoes the last change.
