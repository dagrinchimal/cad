A cone, or a cut-off cone with a top radius.

## How to use
1. Click or type the base center.
2. Type the base radius.
3. Type the height, or `T` (**Top radius**) first for a cut-off cone (frustum).

## Tips
- Combine shapes with [Union](help:union), [Subtract](help:subtract) and [Intersect](help:intersect).
- In the plan you see the solid from above; type `VIEW3D` to see it in 3D.
