Draws a smooth curve that passes through every point you pick.

## How to use
1. Start **Spline** and click the first point.
2. Click the next points; the curve updates as you move.
3. Press **Enter** to finish.

## Options
- **Close** (`C`): after three points, joins smoothly back to the start.
- **Undo** (`U`): removes the last point.

## Tips
- Use few points: smooth curves need fewer than you'd think.
- Splines export to DXF as true splines (R2000 and newer).
