A cylinder from a base center, a radius and a height.

## How to use
1. Click or type the base center (`x,y,z` for a height, or click on a solid face in the 3D view to start on it).
2. Type the radius, or `D` for the diameter.
3. Type the height.

## Tips
- Combine shapes with [Union](help:union), [Subtract](help:subtract) and [Intersect](help:intersect).
- In the plan you see the solid from above; type `VIEW3D` to see it in 3D.
