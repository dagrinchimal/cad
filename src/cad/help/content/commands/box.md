A box from two corners and a height.

## How to use
1. Click or type the first corner. Type `x,y,z` to start above the ground (e.g. `0,0,20`).
2. Click or type the other corner, or `C` (**Cube**) for equal sides.
3. Type the height. A negative height goes down.

## Tips
- Combine shapes with [Union](help:union), [Subtract](help:subtract) and [Intersect](help:intersect).
- In the plan you see the solid from above; type `VIEW3D` to see it in 3D.
