Types one or more lines of text. Each line is its own object.

## How to use
1. Start **Text** (`DT`) and click where the text starts (its bottom-left).
2. Type the height (e.g. `3/16"` or `2.5`) and the rotation angle (`0`).
3. Type a line and press **Enter**. Keep typing more lines; press **Enter** on an empty line to finish.

## Options
- **Justify** (`J`): choose which point of the text you click: **Left**, **Center**, **Right**, **Middle**, or two letters for top/middle/bottom and left/center/right (`TL`, `MC`, `BR`…).

## Tips
- Height is the height of capital letters, as it should measure in the drawing. For text that prints 1/8" tall at 1/4" = 1'-0", use 6".
- Double-click text to edit it.
- Text uses your system's TrueType fonts; choose the font in the Properties panel.
