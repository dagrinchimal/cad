Gives solids an exact width, depth and height. Each solid stretches from its lower-left-bottom corner.

## How to use
1. Select solids, start **Size 3D** (or pick them, Enter).
2. Type the new size as `width,depth,height` (e.g. `80,40,30`), or one number for all three. Enter keeps the current size.

## Tips
- In the 3D view you can also drag a selected solid's handles, or click its size numbers.
- Stretching a round shape by different amounts makes it oval.
