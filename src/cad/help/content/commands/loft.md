Makes a solid that blends smoothly from one outline to the next, like a funnel from a square to a circle.

## How to use
1. Draw the outlines on [sketches](help:sketch) at different heights (e.g. a square on XY and a circle on an XY sketch offset 50 up).
2. Start **Loft** and click the outlines in order, bottom to top. Press Enter.

## Tips
- If all the outlines are on the same plane, you're asked for the distance between them and they're stacked that far apart.
- Outlines with the same number of corners blend most cleanly.
