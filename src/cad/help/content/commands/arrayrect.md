Copies objects into rows and columns. The result is a **live array**: change the original and every copy changes with it.

## How to use
1. Select the objects and start **Array** (or start it and select).
2. Type the number of rows, then columns.
3. Type the distance between rows, then between columns (negative goes down or left).

## Changing it later
Select the array to change rows, columns and spacing in the Properties panel. [Explode](help:explode) turns it into separate copies.
