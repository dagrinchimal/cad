Places a copy of a block.

## How to use
1. Start **Insert** (`I`) and type the block name (the prompt lists them).
2. Click where it goes. The preview follows the cursor.
3. If the block has attributes, answer each question (or press **Enter** for the default).

## Options
- **Scale** (`S`): size of the copy (negative mirrors it).
- **Rotate** (`R`): angle of the copy.

## Tips
- Double-click an inserted block to edit its attribute values.
