Joins solids into one solid.

## How to use
1. Start **Union**.
2. Select the solids (at least two), press Enter.

## Tips
- Solids that don't touch still become one object (with separate pieces).
- [Extrude](help:extrude) › **Join** does extrude-and-union in one step.
