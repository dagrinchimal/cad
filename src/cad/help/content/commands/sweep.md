Moves a closed outline along a path to make pipes, rails, gaskets and mouldings.

## How to use
1. Draw the cross-section (e.g. a circle) and the path (a line, arc, polyline or spline).
2. Start **Sweep**, select the cross-section, press Enter.
3. Click the path.

## Tips
- The cross-section is moved to the start of the path and kept square to it, so you can draw it anywhere.
- Sharp corners in the path make mitred (sharp) corners in the solid.
- Draw the cross-section on a sketch square to the path's start if you want to control its direction exactly.
