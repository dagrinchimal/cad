Writes a paragraph of text inside a box. Lines wrap to the box width.

## How to use
1. Start **Multiline Text** (`T`).
2. Click two corners of the box (its width sets the wrapping).
3. Type the text in the window that opens. Press **Enter** for a new line; click **OK** when done.

## Options
- **Height** (`H`): set the text height before drawing the box.

## Tips
- Double-click to edit. Change the box width, font or attachment in the Properties panel.
