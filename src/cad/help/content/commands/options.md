Program settings.

## Settings
- **Theme**: dark or light.
- **Interface size** and **Text size**: make buttons and text bigger (useful on high-resolution screens).
- **Autosave every**: minutes between safety copies (or Off).
- **Display engine**: Automatic (recommended), OpenGL (fast) or Software (if the screen ever shows problems).
- **DWG converter**: where the ODA File Converter is, if it isn't found automatically.

The bottom of the window shows where settings, autosaves and your plugins folder are.
