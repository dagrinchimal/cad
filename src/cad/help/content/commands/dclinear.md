Locks the horizontal or vertical distance between two points to a value. Change the value and the shape follows.

## How to use
1. Start **Linear Constraint** (`DCL`).
2. Click near the first point, then near the second.
3. Click where the constraint dimension goes: above or below for horizontal, beside for vertical.
4. Type the value (any unit) or a formula like `d1*2`, or press **Enter** to keep the current size.

## Tips
- Change it later in [Parameters](help:parameters).
