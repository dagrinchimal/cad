Adds a fill-in field (like a door number, TITLE or DATE) to include in a block. When the block is inserted you're asked for its value.

## How to use
1. Start **Define Attribute** (`ATT`).
2. Type the tag (no spaces, e.g. `DOORNO`), the question to ask, and the default value.
3. Click where the text goes and type its height.
4. Include it in the selection when you [create the block](help:block).
