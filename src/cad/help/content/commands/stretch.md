Stretches objects: the points inside a crossing window move, everything else stays put. Ideal for making a room longer.

## How to use
1. Start **Stretch**.
2. Drag a window from **right to left** (a crossing window) around the ends you want to move.
3. Click a base point, then the destination (or type `@3',0`).

## Tips
- Objects entirely inside the window simply move.
- For a single corner, a [grip](help:gripedit) is quicker; for an exact length, click the length number ([Click a number to change a size](help:value-editing)).
