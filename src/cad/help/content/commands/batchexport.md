Exports the drawing to several formats at once, into one folder.

## How to use
1. Start **Batch Export**.
2. Tick the formats, choose the folder and the file name.
3. Click **Export all**. A report shows what was written.

## Tips
- Each format uses the options you last chose for it in [Export](help:export). Paper formats include the model and every layout.
