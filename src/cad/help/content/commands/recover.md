Opens drawings that were saved automatically before the program closed unexpectedly.

## How to use
Start **Recover** from the File menu. Pick a drawing from the list and open it; then save it under a proper name.

## Tips
- After a crash, the program offers this by itself the next time it starts.
- How often autosave runs is set in [Options](help:options).
