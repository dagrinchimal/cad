Adds the objects of a DXF, DWG or SVG file into the drawing you have open (one undo step). The new objects are selected so you can move them.

## How to use
1. Start **Import** (`IMP`) and choose the file.
2. The objects arrive at their original coordinates, selected; [Move](help:move) them if needed.

## Tips
- Layers, linetypes and blocks come along; ones you already have keep your settings.
- Holding **Ctrl** while dropping a file on the window does the same.
- A report lists anything that couldn't be brought in.
