- **Click** an object to add it to the selection.
- **Drag left to right** (a **window**, solid outline): selects objects entirely inside.
- **Drag right to left** (a **crossing** window, dashed): selects everything the box touches.
- **Shift + click** or **Shift + drag** removes from the selection.
- **Ctrl+A** selects everything; **Esc** clears the selection.
- Clicking one object of a [group](help:group) selects the whole group.

You can select first and then start a command (it uses the selection), or start the command and then select and press **Enter**.

Right-click with objects selected for a quick menu (Erase, Move, Copy, Rotate, Scale, Mirror, Explode, Group, Properties). Double-click text, dimensions and blocks to edit them.
