## Keys
| Key | Does |
|---|---|
| Enter or Space | Finish the current step; with no command running, repeat the last command |
| Esc | Cancel the command; press again to clear the selection |
| Delete | Erase the selected objects |
| Ctrl+Z / Ctrl+Y | Undo / Redo |
| Ctrl+N / Ctrl+O / Ctrl+S / Ctrl+Shift+S | New / Open / Save / Save As |
| Ctrl+P | Plot (print) |
| Ctrl+A | Select everything |
| Ctrl+1 | Properties panel |
| F1 | Help on the current command or the button under the mouse |
| F3 / F7 / F8 / F9 / F10 / F11 | Object snap / Grid / Ortho / Snap / Polar / Tracking |
| Shift (held while drawing) | Ortho on or off for that moment |
| Mouse wheel | Zoom; drag the wheel to pan; double-click the wheel to see everything |

## Short command names
Type these and press **Enter**: `L` Line · `PL` Polyline · `C` Circle · `A` Arc · `REC` Rectangle · `POL` Polygon · `EL` Ellipse · `SPL` Spline · `H` Hatch · `M` Move · `CO` Copy · `RO` Rotate · `SC` Scale · `MI` Mirror · `O` Offset · `TR` Trim · `EX` Extend · `F` Fillet · `CHA` Chamfer · `AR` Array · `BR` Break · `J` Join · `X` Explode · `S` Stretch · `E` Erase · `DLI` `DAL` `DAN` `DRA` `DDI` `DOR` dimensions · `LE` Leader · `DT` Text · `T` Multiline text · `B` Block · `I` Insert · `G` Group · `LA` Layers · `Z` Zoom · `P` Pan · `PR` Properties · `DI` Distance · `UN` Units · `DS` Drafting settings · `PAR` Parameters.

You can also type part of any name or what you want to do; the command line suggests matches.
